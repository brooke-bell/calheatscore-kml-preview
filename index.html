CalHeatScore KML Data

This page hosts the current CalHeatScore forecast as KML files for Google Earth, broadcast graphics and GIS software, along with GeoJSON, shapefile and ready-made map images. Each file covers every California ZIP code, colored by its CalHeatScore for that day. The files are refreshed twice daily, at about 5:45 AM and 8:45 AM Pacific Time.

Using the data

Each Day KML includes the fields CHS (that day's score, 0–4), CHS_LABEL and VALID_DATE, so graphics and GIS software can color or label ZIP codes with a single template that works for every day. The GeoJSON and shapefile carry all 7 days as CHS_Day_0 (Day 1) through CHS_Day_6 (Day 7). The map images can be used as-is in broadcasts, web stories and social posts.
